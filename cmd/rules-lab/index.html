Walk through this PR

One boundary, three details

1. Start at the first character

The opening marker is exactly --- followed by LF or CRLF. A leading blank line, indentation, or extra marker character fails.

Try Leading blank or No frontmatter.

2. Find the first closing line

The closing marker must be on its own line. It can be followed by LF, CRLF, or end of input. Later delimiters belong to the body.

Try Extra delimiter or Indented close.

3. Preserve both captures

The function returns the original strings. Spaces, tabs, Unicode, and line endings inside each section stay intact.

Try CRLF, Whitespace, or Empty body.
