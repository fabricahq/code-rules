What this PR does

Build verifies snapshot bytes and library content, loads local rules, resolves definitions, renders output, and uses the writer to update only generated/.

Check follows the same pipeline and returns added/changed/removed generated paths without writing files, acquiring a lock, running recovery, or using Git. Empty differences mean output matches.
