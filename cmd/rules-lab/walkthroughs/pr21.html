What this PR does

The adapter creates a temporary directory, writes your fixture there, calls the real Go loader, and removes that directory before returning. The loader itself performs reads only. filesRead shows exact text read from the fixture; the Go catalog retains byte slices. Empty groups remain visible. Missing metadata, malformed selected rules, and observed symlinks fail without a partial catalog.

ok: true means Go returned no error. value contains its result. ok: false includes the returned error and its location. Input text is never inserted as HTML.

Review boundaries

You cannot choose a host directory from this page. The loader receives an already-open, caller-owned filesystem root. It reads selected groups and declared terms, preserves original bytes, and checks cancellation and limits. Supporting assets and Markdown link closure are left for later import work. Unselected groups are not parsed. No existing project files are written.
