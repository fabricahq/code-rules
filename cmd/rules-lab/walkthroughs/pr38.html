            What this PR does
            

              Native archives contain one compiled executable and installation
              guidance. The manifest records the target, source identity,
              version, sizes, and SHA-256 checksums. Installation verifies the
              archive before creating a new directory. Checksums detect
              corruption; obtain both manifest and archive from a trusted
              source.
            

            

              This page executes the compiled code-rules binary directly,
              without a shell. The lab envelope reports whether it captured the
              process successfully; the command's own exitCode determines
              success. Before/after files come from an isolated disposable
              project.
            

            

              Each scenario runs a short sequence of real native commands and
              stops on the first nonzero exit. File paths stay inside a
              disposable project. No source is fetched by this walkthrough.
