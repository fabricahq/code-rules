What this PR does

The production Cobra entry point now exposes sync, build, check, help, and version. Results are human-readable by default; operation and usage errors go to stderr. Add --json for one structured response on stdout, including errors. JSON mode never prompts. Exit 0 means success, exit 1 means operation failure or stale check output, and exit 2 means invalid usage.

This page executes the compiled code-rules binary directly, without a shell. The lab envelope reports whether it captured the process successfully; the command's own exitCode determines success. Before/after files come from an isolated disposable project.

CLI arguments in this demo are confined to these commands and .code-rules/config.json. Source addresses must match prepared local Git fixtures. The production CLI accepts ordinary configured repositories.
