What this PR does

Reads Git tree metadata and only selected blobs, without a checkout. Local and Git libraries use the same rule, license, and attachment validation.

The lab creates real tagged repositories from the editable file trees. All repository addresses must be git@fixture.invalid: followed by the source alias. A private local SSH transport serves those repositories; no external server is contacted.

Catalogs contain parsed rules. Vendor files contain the original bytes plus verified _source.json records. Binary files are explicitly labeled as base64. Both temporary fetch repositories and lab fixtures are removed after the operation.
