What this PR does

WithWriter owns an exclusive lock and recovers an interrupted update. Apply stages complete vendor/generated trees, rechecks inputs, and records before/after digests before renaming directories.

On failure, recovery restores backups only when doing so will preserve later edits. A committed transaction only needs cleanup. Read-only calls refuse pending writes or recovery.

ok: false means the native call returned an error. observation is the lab's separate read of what remains on disk, including preserved edits. The lab always deletes its disposable project afterward.
