How to read the response

ok: true means the Go function returned no error. The group-ID adapter echoes the validated input as value. Rule paths return their group; selections return a sorted list or an unexpanded wildcard.

ValidationError is a returned Go error for invalid domain input. AdapterError means the request could not reach a function, for example because its JSON was malformed. Go returns errors; it does not throw exceptions here.

Walk through the change

Three boundaries to review

1. Rules package

internal/rules owns syntax and error ordering. It uses explicit return values, one typed validation error, and no filesystem or process APIs. Paths always use forward slashes.

Try techs/go/../rule.md. It must fail containment before any later rule or group check.

2. Comparison tests

Shared cases carry independent expected values and errors. The comparison invokes the existing TypeScript implementation and this compiled Go adapter, then checks each against those expectations.

Try a duplicate invalid ID, then add an empty entry. The first reported error changes because validation order matters.

3. Development lab

cmd/identity-lab supplies this page, a fixed HTTP endpoint, and a JSON-lines adapter for tests. It contains no domain validation rules.

Cobra belongs to the future product CLI. This executable is only a development tool.

What this slice establishes

This is syntax validation. A valid ID does not prove a group exists, and a valid rule path does not prove a file exists. Wildcards remain strings until a later import capability expands them. No files are written by these three functions.

Contract coverage and remaining work

These checks provide partial evidence for formats.identities.01–04: empty and multiple selections, wildcard syntax, duplicates, and path traversal. The broader contract remains pending: group discovery, missing groups, wildcard expansion, case collisions, general UTF-16 ordering, and full configuration validation are later work.

Cross-runtime string parity currently covers Unicode scalar text. Lone UTF-16 surrogates in JSON require a separate compatibility decision before the full configuration contract can be accepted.
