The Code Rules mark is the Corner check: a rule card with an open corner and a clear checkmark.
It represents guidance that helps an agent follow a proven practice.
Use these assets when you link to Code Rules, write about it, or build an integration.

## Logos

Use the dark logo on light backgrounds and the white logo on dark backgrounds.
The wordmarks are outlined, so they need no installed font.
Show the horizontal logo at 160px wide or larger; below that, use the symbol.

## Colors

The identity uses one flat color at a time on a grayscale palette.

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#1C1C1C` | The dark logo, symbol, and favicon glyph |
| App tile | `#202020` | The dark app icon and favicon tile background |
| White | `#FFFFFF` | The white logo and the light app icon background |
| Surface | `#F6F6F6` | Light panels behind the dark logo |

## Typography

The wordmark is set in Inter Semibold with tight letter spacing.
The downloadable logos contain vector outlines, so they render identically without the font.
When you set "Code Rules" in running text, use your own typeface; do not recreate the wordmark.

## Usage guidelines

- Keep the symbol upright and proportional. Preserve the open corner, rounded strokes, and check angle.
- Keep at least two stroke widths of clear space around the symbol. The exported logos and app icons already include padding.
- Use one flat color. Avoid gradients, shadows, outlines, and text inside the symbol.
- Use the white logo on dark backgrounds and the dark logo on light backgrounds.
- Use the dedicated favicon exports at 16 to 48px and the horizontal logo at 160px wide or larger.
- Do not combine the symbol with another product's mark or use it to suggest endorsement.
