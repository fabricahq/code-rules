# Release requests

The agent writes one `v<semver>.md` file here per release. The first is `v0.1.0.md`.

Edit the notes in the release PR, save your changes, and merge the PR to authorize publication. CI tests and builds the approved commit, uploads assets to a draft, verifies them, and publishes last.

Follow [the release procedure](../_internal/releasing.md) for drafting, version selection, and retries. This directory intentionally contains no initial release request until the maintainer asks to make that release.
