## ✨ New Features

### Set up a project and write your own rules

Run `code-rules project init` in your repository, then add project-only groups and rules with `code-rules project add group` and `code-rules project add rule`. Each command prompts you for what it needs, or takes flags such as `--non-interactive` and `--json` for agents and scripts. A new rule starts as an unfinished draft, and drafts stay out of the generated guidance until you complete them. (#7, #52, #55, #59)

### Import and customize shared rules

Add a shared rule library with `code-rules project add library`, then run `code-rules project sync` to fetch it and generate guidance. A project can use several libraries, pick the groups it wants, exclude individual rules, and replace an imported rule with its own version.

Pin a library to a tag or commit, or choose a version range such as `>= 1.2.0, < 2.0.0`. Code Rules keeps a snapshot of each imported library and records exactly which commit it used. (#2, #5, #6, #40)

### Generate guidance and check it offline

`code-rules project build` turns your rules and library snapshots into readable Markdown for coding agents, without fetching anything. Indexes help agents find the rules that apply to a task, and provenance records where each rule came from, including replacements and license terms.

`code-rules project check` confirms the generated guidance is up to date without changing any files, and explains how to fix it when it isn't, so it works well in CI. It checks your rule files, not whether your code follows the rules. (#3, #40)

### Publish your own rule libraries

Create a library with `code-rules library init`, add groups and rules with `code-rules library add group` and `code-rules library add rule`, and share it through Git. Run `code-rules library check` first to validate its metadata, rules, attachments, links, and license files. (#8, #40, #55)

### Install on macOS and Linux

Install the standalone `code-rules` binary with the install script or Homebrew:

```sh
curl -fsSL https://code-rules.fabricahq.com/install.sh | sh
brew install fabricahq/tap/code-rules
```

Releases include binaries for macOS and Linux on `amd64` and `arm64`, with checksums and signed build provenance. Native Windows isn't supported yet. See [Install Code Rules](https://code-rules.fabricahq.com/start-here/install/). (#43, #47, #51)
