Code Rules is the package manager for engineering best practices. This first release lets you version rules, share them across projects, and generate guidance for coding agents.

## ✨ New Features

### Set up a project and author rules

Start with `code-rules init`, then create groups and rules with `code-rules local add group` and `code-rules local add rule`. Authoring commands provide terminal prompts and explicit flags for scripts. Generated project and group guides explain how agents should manage the rules.

### Import and customize shared practices

Use `code-rules add source` to configure Git libraries, then run `code-rules sync` to fetch and generate guidance. Projects can use several libraries, select groups, exclude individual rules, add local rules, and replace imported rules.

Pin a source to a commit or tag, or select versions with constraints such as `>= 1.2.0, < 2.0.0`. Imported snapshots retain original files and record the resolved commits.

### Generate guidance and check it offline

`code-rules build` generates readable Markdown from local rules and verified library snapshots without fetching remote changes. Discovery indexes help agents find applicable rules; provenance records where the guidance came from, including replacements and declared terms.

`code-rules check` verifies generated guidance and the project guide without changing files. Stale output fails with repair instructions, making the command useful in CI. It checks rule-file consistency, not whether application code follows the rules.

### Publish your own rule libraries

Use `code-rules library init`, `code-rules library add group`, and `code-rules library add rule` to create a library. Run `code-rules library check` to validate metadata, completed rules, attachments, links, and declared license files before sharing it through Git.

### Run a standalone CLI

Release archives provide standalone binaries for macOS and Linux on `amd64` and `arm64`. Each archive includes the MIT license, and `SHA256SUMS` lists archive checksums. Native Windows is not supported.

Run `code-rules --help` for commands and examples. Add `--json` for structured output in scripts.
