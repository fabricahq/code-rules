# Code Rules: native CLI, one command at a time

This supplementary runbook covers PRs 34, 35, 36, and 39. Keep the [4391 review collection](http://127.0.0.1:4391/) open for each PR's other scenarios.

Run each block in order and wait for it to finish. Expand its script to see the exact commands, then inspect live stdout and exit status.
All commands write inside a fresh temporary workspace. The workspace stays on disk for inspection. Restart **Prepare** for a fresh run; do not rerun the add commands against existing files.

Use **Generated Files** to inspect snapshots after Initialize and each file-changing step. Each command prints its working directory; the file viewer shows snapshots, not a live filesystem.
CLI results use readable text by default. Add `--json` for a structured response, including errors. Step 6 demonstrates both formats.
The **Observe the expected check failure** block deliberately turns red. It demonstrates an error you should see, not a broken runbook.
